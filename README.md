## 🌟 About the Project

An **interactive web-based presentation** designed to showcase the Campus Ambassador Program in a **modern, engaging, and user-friendly way**.

Unlike traditional slides, this project delivers a **smooth digital storytelling experience** that captures attention and improves communication.

## 🎯 Key Highlights

✨ Interactive slide-based navigation
🎨 Modern UI with smooth transitions
⚡ Lightning-fast performance using Vite
📱 Fully responsive design
🧩 Modular component-based architecture
